# NIRA SOLUTIONS

Marketing website for NIRA SOLUTIONS — integrated manpower, consulting and technology.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS
- Motion (Framer Motion)
- Lenis smooth scroll
- Vercel-ready

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Push to GitHub and import the repo in [Vercel](https://vercel.com), or:

```bash
npx vercel
```
